# AuraTracker seed visuals

These assets were generated specifically for the AuraTracker demo seed with the built-in OpenAI image generation tool. They replace the generic stock-photo aliases previously stored under `images/mock`.

## Production prompt set

All prompts required: original fictional subjects, no text, no logo, no watermark, natural materials, and a composition safe for the UI crop described below.
